# Variables and error budget

The table uses \(v\) for a geometric word, \(z\) for a translate and \(\mathcal L\) for a character level. These distinguish three uses of similar names in the source. An explicit degree in \(m\) below holds with the other coefficients frozen. The right column states the bounds that survive a change to another admissible record. Source keys are in [the source index](amplifier-sources.md). Equations refer to [the scalar model](amplifier-equations.md).
